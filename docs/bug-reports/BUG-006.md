# BUG-006

## Summary
Capture progress is not displayed in text on the player's screen.

## Severity
Trivial

## Priority
Low

## Environment
- Scene: `MainScene`
- Platform: Windows

## Preconditions
- MainScene is on
- Capture point exists
- Player is alive
- Capture progress is 0 in capture point

## Steps
1. Move player into capture zone
2. Wait until capture progress becomes greater than 0
3. Observe capture progress

## Expected Result
Capture progress is displayed in text on the player's screen and increasing by an amount equal to "number of seconds * number of captures per second".

## Actual Result
Capture progress is not displayed in text on the player's screen. Only in debug overlay.
