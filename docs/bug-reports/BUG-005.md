# BUG-003

## Summary
Capture progress is not reset after player leaves the capture zone.

## Severity
Blocker

## Priority
High

## Environment
- Scene: `MainScene`
- Platform: Windows

## Preconditions
- MainScene is on
- Capture point exists
- Player is alive
- Capture progress is 0 in capture point

## Steps
2. Move player into capture zone
3. Wait until capture progress becomes greater than 0
4. Move player out of capture zone
5. Observe capture progress

## Expected Result
Capture progress should reset to 0 by an amount equal to "number of seconds * number of captures per second" when the zone becomes empty.

## Actual Result
Capture progress remains frozen at the last value.
