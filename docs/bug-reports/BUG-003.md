# BUG-003

## Summary
Player can fire a weapon even without ammo

## Severity
Critical

## Priority
High

## Environment
- Scene: `MainScene`
- Platform: Any
- Weapons: Any

## Preconditions
- Player is alive
- Player is not reloading
- Ammo in magazine is 0
- Ammo reserve is 0

## Steps
4. Press left mouse button
5. Observe to the shot fired from the weapon and ammo in the magazine

## Expected Result
Weapon should not fire. Ammo should remain 0 in magazine.

## Actual Result
Weapon continues to fire regardless of remaining ammo
