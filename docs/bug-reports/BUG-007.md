# BUG-007

## Summary
Capture progress continues by dead players

## Severity
Critical

## Priority
High

## Environment
- Scene: `MainScene`
- Platform: Windows

## Preconditions
- MainScene is on
- Capture point exists
- Player is alive and is not inside capture zone
- Second player alive (to deal damage) and is not inside capture zone
- Capture progress is 0 in capture point

## Steps
1. Move player into capture zone
2. Kill player
4. Observe capture progress

## Expected Result
Capture progress should reset to 0 by an amount equal to "number of seconds * number of captures per second" when the zone becomes empty (because alive players are not in capture zone).

## Actual Result
Capture progress continues by dead players
