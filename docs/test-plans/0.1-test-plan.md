# Test Plan v0.1

## 1. Purpose
It is better to draw up a real test plan in a specialized application (for example, HP Alm or Jira tools, here a simulation is used for ease of verification)

This test plan defines the test scope and the exact set of test cases that must be executed for the current version of game.
The goal is to validate core gameplay systems and identify defects in player control, weapon logic, vehicle interaction, vehicle damage, and capture point behavior.

## 2. Test Object
Project: Combat QA Sandbox  
Version: v0.1
Test type: Manual functional testing
Platform: Windows

## 3. Test Scope
- player movement
- weapon firing
- reload logic
- vehicle enter and exit
- vehicle movement
- engine module damage
- capture point progress

## 4. Out of Scope
- multiplayer
- AI
- performance
- audio
- realistic ballistics
- advanced vehicle physics
- save/load
- visual polish

## 5. Entry Criteria
- Project opens without compilation errors
- `MainScene` starts in Play Mode
- Smoke tests pass successfully

## 6. Exit Criteria
- all test cases from this plan are executed
- failed cases are linked to bug reports
- No critical or blocker level bugs
